--------------------------------------------------
POUR OUVRIR SUR L'ORDINATEUR
--------------------------------------------------
Double-cliquez sur "index.html".

--------------------------------------------------
POUR METTRE EN LIGNE SUR GITHUB (remplacer l'ancienne version)
--------------------------------------------------
1. Ouvrez votre dépôt GitHub (road-trip-maroc).
2. Cliquez "Add file" > "Upload files".
3. Faites glisser TOUT le contenu de ce dossier
   (index.html, app.js, styles.css, sw.js, manifest.webmanifest,
    et les dossiers data, vendor, assets).
4. Cochez "Commit directly to the main branch" puis "Commit changes".
5. Attendez 1-2 min : le site se met à jour tout seul.

Astuce téléphone/ordinateur : si l'ancien affichage reste,
faites Ctrl+Maj+R (ordinateur) ou fermez/rouvrez l'onglet.
